# dCA1_Paper
 Repository for analysis of dCA1 paper.

 Folder structure required for onephoton.py - InscopixProcessing:
 - base_directory/metadata_file.csv (csv file with animals, groups, sessions)
 - CellReg outputs:
    base_directory/CellReg/{animal}_FOV1
    see cell_registration README for additional subfolder info & instructions for CellRegß
 - Inscopix traces csv files:
    base_directory/Cell_Traces/{animal}_traces/{animal}_{session}_traces.csv
